# Analytics status

The only analytics integration in the app is optional Firebase Analytics. It is disabled by default through `NEXT_PUBLIC_ENABLE_ANALYTICS=false`.

Before enabling it, complete the owner gates in [`PUBLIC_LAUNCH_GATES.md`](PUBLIC_LAUNCH_GATES.md) and the setup steps in [`ANALYTICS_SETUP.md`](ANALYTICS_SETUP.md). The older setup text described Firebase Authentication and outdated Google Analytics goals; do not follow those instructions.
